# 功能總覽

Itoy 的台股監控看板以台灣上市、上櫃股票為範圍，提供市場觀察、客觀篩選、自選追蹤、多股比較與條件監控。逐頁操作請見 [操作說明書](../操作說明書.md)，設定與部署請見 [設定說明](./configuration.md)及[部署說明](./deployment.md)。

## 看板

- 顯示今日漲跌家數、市場強弱、產業強弱與台股資料狀態。
- 彙整自選股動態與最近的監控觸發記錄。
- 缺少或尚未更新的資料會顯示狀態，不以數值零代替。
- 策略當日推薦（看板卡片與策略庫「策略清單」）把各策略選股分為「買進」與「觀察」：每支策略前 5 名為買進，有評分設定的策略另需分數大於 0；複合策略與沒有評分設定的策略只看排名。
- 大盤濾鏡：選股基準日加權指數收盤低於 20 日均線時，所有買進降為觀察並標示原因；指數資料不足或缺日時不降級，標示「大盤狀態無法判定，濾鏡未套用」。盤中更新的結果沿用最近一次收盤的大盤狀態並標出日期。分級僅供參考，不保證獲利，投資風險自負。

## 台股選股

- 使用 TWSE、TPEx 公開資料建立全市場量化統計快照。
- 提供產業輪動、客觀異常訊號、常用篩選，以及技術面與法人籌碼條件。
- AI 自然語言解析只把文字轉成可預覽的篩選條件，不直接推薦股票，也不自動執行投資決策。
- 量價型態：倍量、梯量、縮量、低量、平量、放量滯漲 6 種，於盤後發佈時計算；可在進階條件多選（同時符合），結果表列出每檔命中的型態。發佈前的舊資料沒有型態欄位時會顯示「量價型態尚未發佈」。

## 策略庫：事後統計

- 每個交易日盤後重算策略時，記錄當日各策略的選股快照（`data/user_data/strategy_picks/`）；下一個交易日開盤後只接受策略設定未變的覆寫，日 K 出現下一個交易日後即鎖定。
- 以 T+1 開盤價為起點，用含現金股利的除權息調整計算 T+1／5／10／20 的持有期報酬；開盤即漲停、無成交或停牌的標為未成交。
- 各策略顯示樣本數、平均與中位數報酬，以及「報酬為正比例」；報酬為毛報酬，未扣交易成本、未計滑點、未模擬出場可成交性。
- 成交代表訊號後次一交易日開盤價的模擬買入，不是帳戶的實際成交；T+k 報酬為訊號後第 k 個交易日復權收盤價除以次日復權開盤價再減一，T+1 即次日開盤至收盤。
- 「補算歷史訊號」預設計算最新完整日 K 以前 5 個本機行情交易日（不含最新日），可改為 1 至 250 日。只補缺少的策略日，已有快照不覆寫，重跑不重複增加紀錄；零訊號仍保存計算清單，但不增加訊號日數。缺資料或策略失敗會列出未能計算的策略日。
- 歷史補算使用目前策略版本、參數與股票池，標示「依目前策略重建歷史」，保存真實補算時間與策略指紋，不能視為當時已記錄的訊號。重建與盤後實際記錄的筆數會分別標示；重建訊號可累計訊號日數與成熟報酬。
- 歷史換手率缺少當時可用的股本時維持不可計算，不用目前股本回填。策略必備篩選輸入缺失會列為未能計算，不能解讀為零訊號。只有評分資料缺失且完整候選未受排名截斷影響時，保留候選與報酬、將分數設為空值並提示列序不是有效排名；可能影響候選選取時則不記錄訊號。
- 除權息資料不可用時不計算報酬，也不改用未還原價格；市場資料不完整與清單缺漏的選股不計入績效。實際盤後記錄若延遲仍排除，明確標示的歷史重建則允許納入。
- 統計只描述過去選股的結果，過去表現不代表未來，建議僅供參考，不保證獲利，投資風險自負；重建資料不還原當時的策略設定、財務資訊或股票池。

## 自選股與多股比較

- 自選股支援分組、表格或卡片檢視、自訂欄位、迷你日 K 與分時資料。
- 多股比較並列報酬率、法人買賣超、本益比與異常訊號等客觀資料。
- AI 比較是選配功能，只有使用者手動觸發時才會呼叫已設定的模型。

## 個股頁面

- 顯示歷史日 K、成交量、即時報價與五檔盤口。
- 顯示三大法人、融資融券、券資比與核心籌碼滾動因子。
- 漲跌幅限制依標的與交易日規則判定；無漲跌幅限制或資料不足時明確標示不可用。

## 監控中心

- 支援價格、漲跌幅、成交量與接近漲跌停等規則。
- 支援冷卻時間、遲滯防抖、觸發記錄及 LINE／Telegram 推播。
- 推播渠道各自設定與測試；未設定外部渠道時，本機監控與記錄仍可使用。

## 資料與擴充

- 預設資料來源為 TWSE／TPEx 官方公開資料，不需要付費行情 API Key。
- 歷史日 K 可由 GitHub Release 資料包匯入，再補齊到最近交易日。
- 盤後排程與設定頁的「更新到最新」會先補抓加權指數日 K，供大盤濾鏡使用；補抓失敗只記錄，不影響日 K 與策略更新。
- 資料在本機以 Parquet／DuckDB 儲存；資料來源可依既有 provider 與插件契約擴充。
- 自訂資料來源請見 [自訂資料來源](./custom-data-source.md)與[插件開發](./plugin-development.md)。

本產品不提供因子挖掘、A 股連板分析、舊式策略回測平台或自動下單功能。
